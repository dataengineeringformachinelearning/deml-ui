# deml-ui

**new-from-the-start (warm ash)** — DEML’s component library with dual package builds (**Web Components** + **Angular**).

Style first in Storybook. Ship via `npm run build`. Geist only; dual `data-theme`; WCAG 2.0 AA.

## How to use this Storybook

| Feature | Where |
|--------|--------|
| **Canvas** | Live component preview |
| **Docs** | Autodocs + packaged HTML source (`.demo` fragment) |
| **Theme** | Toolbar — light / dark (`data-theme`) |
| **Viewport** | Toolbar — phone, tablet, desktop, deml widths |
| **Backgrounds** | Toolbar — warm ash / deep surface / cream / light ground |
| **Measure / Outline** | Toolbar — spacing & box inspection |
| **Density** | Toolbar — compact / comfortable / spacious |
| **A11y** | Panel — axe (WCAG 2 A/AA + best practices) |
| **Actions** | Panel — click / submit / change / input |

## Source of truth

`components/<name>/` + `styles/tokens.css`:

- `<name>.html` — Storybook chrome + reusable markup in `.demo`
- `<name>.css` — structure under BEM roots (`.card`, `.button`, …)
- Tokens own palette, type, tile rhythm, and `--chart-aspect: 2.4`

Edit → hot reload. Add/remove a folder → `npm run sync` regenerates stories + wrappers.

## Laws

1. Warm ash NFTS only (`#35312D` / `#1C1916` / `#F3F0EA` / `#D4CEC5` / `#2F5F8F`)
2. Geist for every type role — no Syne / Fraunces
3. Fluid equal cells — `grid-auto-rows: minmax(var(--tile-row-unit), auto)`
4. Charts — width-driven aspect; never squash with fixed-only rows or `height: 100%` on plot stages
5. No Viking-UI / cold seven-color frankenstein

## Sidebar

Each group has a docs landing page (e.g. `?path=/docs/shell--docs`):

1. **Dashboard** — composition example
2. **Shell** — app chrome, page headers, navigation
3. **Layout** — stack, grid, panels, spacing recipes
4. **Forms** — fields, inputs, buttons, switches
5. **Feedback** — badges, callouts, loaders
6. **Data** — cards, metrics, tables, charts
7. **Overlays** — dialogs, sheets, dropdowns

## Package builds

```bash
npm run storybook        # this UI
npm run build            # styles + web components + Angular → dist/
npm run build-storybook  # static site
```

Custom elements use the `deml-*` tag prefix (e.g. `<deml-button>`).

## Angular

Two layers ship from `deml-ui/angular`:

| Layer | What it is |
|-------|------------|
| Markup wrappers | Thin hosts for deml-ui HTML/CSS |
| Headless | Behavior-only primitives under `src/angular/headless/` |
